# ドキュメント

`docs/`

本リポジトリの開発・利用に関する文書を配置する。

## 構成

- `public/` — 開発チーム外との共有を想定する文書（利用者向け説明、外部I/F説明等）。
  該当文書が無いプロジェクトでは存在しない場合がある。
- `devel/` — 設計・開発・テスト・運用・保守に必要な開発内部文書。
  開発者・コーディングエージェントが主に参照する。

## 機密情報

本ディレクトリ配下には以下を含めない。

- 認証情報、APIキー、秘密鍵、トークン
- 本番環境のDB接続認証情報
- 顧客個人情報、契約条件のうち機密相当部分
- 未公表のセキュリティ脆弱性詳細

これらが文書として必要な場合は、Secrets管理（環境変数、Vault、Secret Manager等）
への参照のみを記載する。
