# 運用

`docs/devel/operation/`

リリース後・稼働中のシステムに関する文書を管理する。

本番稼働を伴うシステムでは必須。ライブラリ、PoC、社内検証用ツールなど本番稼働を
持たないプロジェクトでは任意。

## 配置するもの

- リリース手順 / デプロイ手順 / 切り戻し手順
- 監視項目 / ログ確認方法
- 障害時対応
- バックアップ・リストア
- 定期メンテナンス
- 証明書更新 / 依存関係更新

## 隣接カテゴリとの境界

- 設計内容（インフラ構成、運用設計） → `../design/architecture/`
- 採用した運用方式の理由 → `../adr/`

## 規模が小さい場合

`operation.md` 単一ファイルで運用してよい。
