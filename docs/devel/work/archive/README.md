# アーカイブ

`docs/devel/work/archive/`

古くなった・失効した作業文書を管理する。

完了直後のタスクは `../tasks/done/` に置く（ここではない）。参照頻度が
下がった段階で archive へ移す。

## 配置するもの

- 古くなった完了タスク（`../tasks/done/` から移動した `task.<milestone>.md`）
- 失効した backlog 項目
- 古い調査メモ
- 過去のレビュー結果
- 履歴的価値のあるメモ

## 削除との使い分け

- 今後参照しない → 削除可
- 判断履歴として残す必要がある → `../../adr/` へ反映してから削除
- 振り返りで使う可能性がある → archive に保持
