# テスト

`docs/devel/testing/`

テストの**方針・実行方法・設計ルール**を管理する。テストコード本体は配置しない。

テストコードは各プロジェクトの標準的なテストディレクトリ（例: `src/test/`、
`tests/`、`e2e/`）に配置する。

## 配置するもの

- テスト方針 / テストレベルの使い分け
- 単体・結合・E2E テストの対象範囲
- 手動確認に残す範囲
- テストデータの扱い
- ローカル実行方法 / CI実行方法
- カバレッジの考え方
- テスト自動化方針

## 隣接カテゴリとの境界

- 何を満たせば品質十分か → `../quality/`
- 一時的なレビュー結果 → `../work/reviews/`

## 規模が小さい場合

`testing.md` 単一ファイルで運用してよい。
